How many pupils chose each fruit? Which shape appears most often in a box of blocks? Collecting and organising information helps children answer questions using evidence rather than a guess.

Primary data work begins with sorting real objects and keeping careful counts. Tables, pictographs and bar charts then give different ways to display the same information. A child should be able to explain what a display represents, not only name the tallest bar.

All the fruit counts on this page are invented teaching examples, not results from a survey or claims about children's preferences.

How data work develops

  • Class 1: sort objects by an observable feature and compare groups using counting.
  • Class 2: collect and arrange small sets of information, keeping the categories clear.
  • Class 3: organise counts and read simple displays and tables as introduced in the textbook.
  • Class 4: read and make pictographs, using the key to connect pictures with quantities.
  • Class 5: develop bar-chart work and use displays to compare quantities and answer questions.

Follow the particular textbook for sequencing. Formal averages and line graphs are not core requirements in the current NCERT primary maths books.

Begin with a question that can be counted

“Which of these three fruits would you choose?” is clearer than “What is your favourite food?” when the plan is to compare three fruit categories. Tell each participant to choose one option if the total is meant to represent people.

Keep categories separate. If the choices are banana, mango and guava, record a mango choice under mango, not under a second category such as “sweet fruit”. Overlapping categories can count the same response twice.

For classroom practice, use anonymous choices and small, non-sensitive questions. There is no need to collect names, marks, family income or other personal details to learn graph skills.

Agree the categories before counting. Afterwards, add the category totals and compare them with the number of responses. If the totals differ, investigate the counting rather than altering the graph to hide the difference.

Tallies help keep track

A tally records one mark for each item or response. After four upright marks, the fifth crosses the group. Grouping in fives makes larger counts easier to read and reduces the chance of losing your place.

For 8 responses, make one group of five and three more marks: 5 + 3 = 8. For 6, make five and one more. A child who writes a fresh numeral after every response can practise tallies with counters first.

When the counting finishes, transfer the totals to a table. The heading should say what was counted and the column labels should identify the categories and their quantities.

Check the total: 8 + 6 + 4 = 18. The table lets us find an exact count without estimating a height or counting pictures.

Pictographs: read the key first

A pictograph uses pictures or symbols to represent quantities. The key tells us the value of one symbol. A symbol does not always represent one response.

For our fruit counts, let one circle represent 2 responses:

FruitSymbols: each ○ means 2 responsesCount
Banana○ ○ ○ ○4 × 2 = 8
Mango○ ○ ○3 × 2 = 6
Guava○ ○2 × 2 = 4

Counting four banana symbols and answering “4” ignores the key. Ask your child to point to a symbol and say how many responses it represents before reading the whole row.

If a count does not fit a chosen key, use a smaller key or a clearly explained part-symbol when appropriate to the textbook. Do not round a count merely to make the pictures fit.

Bar charts: labels, scale, then bars

A bar chart can show the same fruit counts. Categories run along one axis; the other axis has a numerical scale. The bars should have equal widths, gaps between separate categories and a common zero baseline.

The scale increases by 2 at each labelled step. The mango bar reaches 6, not 3: it passes three steps, each worth two responses. Read the scale values rather than count the grid lines.

To draw the chart, start from the table. Mark the scale before drawing bars, keep the spacing consistent, and check each height against the original count.

Ask different kinds of questions

  • Read a value: how many mango responses? 6.
  • Compare: how many more banana than guava responses? 8 − 4 = 4.
  • Combine: how many mango and guava responses together? 6 + 4 = 10.
  • Find a total: how many responses altogether? 18.

“Most popular” only describes the largest count in this example. It does not prove that most children everywhere prefer bananas. A display answers questions about the information actually collected.

I can tell which bar is tallest, but I still need the scale to give its exact value. My eyes are a starting point, not the whole calculation.

Common mistakes

  • Missing the key: read the pictograph key aloud before counting.
  • Unequal scale steps: check that equal distances represent equal numerical changes.
  • Adding category names: add the quantities, keeping the labels alongside them.
  • Making an unsupported claim: distinguish what the display shows from a wider guess.

Practical activities

  • Shape sort: sort a small set of blocks, count each category and make a table.
  • Reading record: use fictional counts of books read to practise bar-chart questions without comparing pupils' performance.
  • Class choices: collect anonymous choices from a short list of games and display the totals.
  • Cricket table: use invented runs from four overs to practise reading and combining entries.
  • Change the display: show one table as both a pictograph and a bar chart, checking that the totals remain unchanged.
